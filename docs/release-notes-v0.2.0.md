## Fake Type v0.2.0

这一版重点重做了代码补全链路，不再把预设字符仅作为普通文档编辑写入，而是让预设字符走 VS Code 原生 typing pipeline，从而让语言服务能够收到正常的 typing 事件并触发 IntelliSense。

### 新增

- 原生 IntelliSense 输入链路：任意键仍输出预设代码，但预设字符通过 VS Code `default:type` 原生处理
- 侧边栏新增“代码补全”面板，可单独开关补全增强
- 三种补全模式：仅原生、原生 + 兜底、持续强制
- 可调补全兜底延迟：0–500 ms
- 三种触发范围：仅标识符、代码字符、所有字符
- 接受 Tab / Enter 补全后自动同步 Fake Type 映射进度
- 可选诊断日志与“测试补全”按钮，方便排查语言服务或 VS Code 设置问题

### 保持兼容

- 保留原有任意按键映射预设代码
- 保留映射进度、撤销同步、删除逻辑
- 保留假终端命令/输出功能
- VS Code 最低版本仍为 1.80.0

### 推荐设置

默认使用“原生 + 兜底”、80 ms、代码字符触发。若当前语言扩展的 IntelliSense 本身工作正常，也可以切换为“仅原生”。
