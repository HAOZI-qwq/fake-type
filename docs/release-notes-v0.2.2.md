## Fake Type v0.2.2

这一版继续修复输入进度同步，重点解决回退键重置进度、接受补全后重复输出，以及快速输入时补全与预设字符互相覆盖的问题。

### 修复

- Backspace / Delete 只回退实际删除的逻辑字符，不再因文档前缀差异把进度重置到开头
- 删除中文、Emoji 和换行时按逻辑字符回退，兼容 CRLF / LF
- 接受 Tab / Enter 补全时依据 VS Code 实际替换范围推进预设索引
- 处理重复代码片段，避免补全文本被错误匹配到后面的同名片段
- 处理补全替换跨越 LF / CRLF 的情况
- 补全覆盖队列中尚未写入的预设字符时，撤销这些预留字符，避免补全后重复输出
- 识别 Fake Type 自己正在写入的字符、选区替换和换行格式，避免误判为外部补全
- 暂停 Fake Type 后进行删除，重新启用时仍能从正确位置继续

### 保持兼容

- 保留 VS Code 原生 `default:type` 与 IntelliSense 输入链路
- 保留任意按键输出预设代码的演示方式
- 保留 Tab / Enter 接受补全后的同步机制
- 保留中文、Emoji、自动缩进和 CRLF / LF 预设内容
- VS Code 最低版本仍为 1.80.0

### 验证

- 新增回退、补全替换、重复片段、跨换行格式、活动写入和队列取消测试
- 共 23 项自动化测试全部通过
