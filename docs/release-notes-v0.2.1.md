## Fake Type v0.2.1

这一版重构了 Fake Type 的输入调度与进度同步，重点解决快速乱敲时重复输出同一个字符，以及 HTML 换行后反复输出缩进空格的问题。

### 修复

- 按键到达时立即预留唯一的下一个预设字符，避免异步写入期间重复读取同一索引
- 所有预设字符、回车和透传输入统一串行处理，保持真实按键顺序
- 队列执行期间延后补全进度同步，防止迟到的文档变化事件把索引拉回旧位置
- 仅允许 Undo、Redo 和写入失败恢复触发进度回退
- 将 CRLF 与 LF 视为等价换行，避免不同换行格式造成进度卡死
- 识别 VS Code 自动缩进或补全已插入的字符，避免重复空格和重复内容
- 切换编辑器时停止向错误文件写入，并按实际文档内容恢复进度
- Backspace、Delete、重置和映射变更会等待输入队列稳定后执行

### 保持兼容

- 保留任意按键输出预设代码的演示方式
- 保留 VS Code 原生 `default:type` 与 IntelliSense 输入链路
- 保留 Tab / Enter 接受补全后的进度同步
- 保留侧边栏补全设置、诊断日志和假终端功能
- VS Code 最低版本仍为 1.80.0

### 验证

- 新增高速连续输入、异步写入、透传顺序、自动插入区间和索引回退测试
- 共 16 项自动化测试全部通过
