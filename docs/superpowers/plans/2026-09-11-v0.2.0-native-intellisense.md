# Fake Type v0.2.0 Native IntelliSense Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Route preset characters through VS Code's native typing pipeline, add sidebar completion controls, preserve mapping/terminal behavior, and publish a tested v0.2.0 VSIX.

**Architecture:** Keep the existing `type` override and queue but replace mapped `editor.edit()` insertion with `default:type`. Move completion policy/settings into focused helper code, wire the existing paste-area webview to the settings model, and use document-change synchronization only to advance preset progress after accepted completions.

**Tech Stack:** TypeScript, VS Code Extension API, Node.js built-in test runner, GitHub Actions, @vscode/vsce.

**Spec:** `docs/superpowers/specs/2026-09-11-v0.2.0-native-intellisense-design.md`

## Global Constraints

- Keep VS Code engine floor `^1.80.0`.
- Preserve arbitrary-key mapped typing behavior.
- Preserve terminal subsystem behavior.
- Native typing path must use `default:type` for mapped characters.
- Completion defaults: enabled, `nativeFallback`, 80ms, `code`, sync enabled, diagnostics disabled.
- Release version: `0.2.0`; tag: `v0.2.0`.
