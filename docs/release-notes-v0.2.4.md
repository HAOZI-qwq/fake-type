## Fake Type v0.2.4

这一版修复 VS Code 自动闭合字符和原生补全候选与预设代码冲突的问题。

### 修复

- 预设右括号、方括号、大括号和引号遇到 VS Code 自动闭合字符时，使用原生越过行为移动光标，不再直接跳过或重复插入
- 输入结构符号前关闭不安全的候选列表，避免提交字符自动接受与预设不一致的原生补全
- 为当前预设标识符生成置顶并预选的精确候选项，按 Tab 后直接推进到对应预设位置
- 只有编辑器中的真实前缀与预设前缀一致时才提供预设候选，防止错误替换
- “仅原生”和“关闭补全增强”模式不会注入预设候选或拦截原生提交字符
- 修复非 BMP Unicode 标识符的预设候选前缀边界

### 验证

- 新增自动闭合越过、预设候选、提交字符保护和设置模式测试
- 共 31 项自动化测试全部通过
